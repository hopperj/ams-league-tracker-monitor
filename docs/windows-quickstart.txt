AMS League Recorder for Windows x64 (Intel and AMD)

One build works on both Intel and AMD 64-bit Windows PCs.
The x64 architecture is also called x86-64 or AMD64; it supports both brands.
Python and the window toolkit are included. No separate Python installation or
compilation is required.

1. Extract this ZIP, then double-click
   AMSLeagueRecorder-Windows-x64-Intel-AMD.exe.
2. In AMS2, select Options > System > Shared Memory > Project CARS 2.
3. Sign in with Steam and approve this recorder in the browser. Use Link Steam
   account if approval does not open. Recording waits for server confirmation.
4. Setup is optional. The default server is https://ams2.ioresearch.ca.
   Leave the capture code as AUTO to record all sessions. Existing settings
   and queued data continue working when upgrading from an older version.

Green / Comms open, awaiting race data means upload access is verified.
Red / Recording in progress means live game data is being recorded and sent.
Amber means a problem needs attention; read the message for the cause.
Gray means checking, stopping or stopped. Communication is checked every five
seconds, even when AMS2 is closed. Data saved - review means the server saved
the upload but has processing notes; later uploads continue.
A league administrator can review those notes in Recording diagnostics.

The app remembers your settings and verifies your Steam link on future launches.
AUTO records solo practice and league driving across tracks and cars. The server
organizes sessions; administrators separately approve official league nights.
Older saved capture codes remain supported. To enable automatic recording, Stop,
open Setup, change the capture code to AUTO, and save/start again.

Failed deliveries remain queued locally and retry. Closing the app retains the
remaining queue for the next launch. Settings, queue, and rotating recorder.log
files are under %LOCALAPPDATA%\AMSLeagueRecorder.

This executable records game data only. The optional UDP archive is available
through the source/portable command-line client.

Source: https://github.com/hopperj/ams-league-tracker-monitor

STEAM ACCOUNT
Sign into the webapp and choose Download my Windows recorder for personalized setup. Extract the whole ZIP, then run the EXE. Your browser asks you to approve this recorder. With a generic download or an existing installation, click Link Steam account. Recording and uploads wait until the server confirms the link. Existing settings and queued data are preserved.

AUTOMATIC UPDATES (0.6.0 AND LATER)
The Windows EXE checks for published updates at startup before recording. A
verified update installs and restarts automatically with your saved Steam link,
settings and queue. You do not need to sign into Steam again for an ordinary
update. Skip update & start uses the installed version; failed checks/downloads
also keep the current version. Running recordings are not interrupted.
Older versions need a one-time download of an updater-enabled Windows build.
