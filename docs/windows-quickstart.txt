AMS League Recorder for Windows x64 (Intel and AMD)

One build works on both Intel and AMD 64-bit Windows PCs.
The x64 architecture is also called x86-64 or AMD64; it supports both brands.
Python and the window toolkit are included. No separate Python installation or
compilation is required.

1. Extract this ZIP, then double-click
   AMSLeagueRecorder-Setup-Windows-x64-Intel-AMD.exe.
   Install once, then open AMS League Recorder from the Start menu or desktop
   shortcut. No administrator password is needed.
2. In AMS2, select Options > System > Shared Memory > Project CARS 2.
3. Sign in with Steam and approve this recorder in the browser. Use Link Steam
   account if approval does not open. Recording waits for server confirmation.
4. Recording is enabled automatically when you open the app. Use Stop to
   pause and Start recording to resume. New installations capture all driving
   sessions by default. Existing settings and queued data survive upgrades.
5. Click Open webapp in the top bar to open your dashboard in the default
   browser. Recording continues while you use the website.
6. Click Join server to launch AMS2 through Steam and join the current dedicated
   server. Private lobbies ask for a password, which is not saved. Recording
   continues while looking up the server and entering its password.

Green / Comms open, awaiting race data means upload access is verified.
Red / Recording in progress means live game data is being recorded and sent.
Amber means a problem has persisted for three seconds. The message shows the
cause as soon as the recorder detects it.
Gray means checking, stopping or stopped. Communication is checked every five
seconds, even when AMS2 is closed. Data saved - review means the server saved
the upload but has processing notes; later uploads continue.
A league administrator can review those notes in Recording diagnostics.

Queued on PC counts samples still waiting to upload from this computer.
Server processing counts samples already saved by the webapp and waiting to
be processed. A server processing queue does not pause recording or uploads.
Older webapps show a dash for this count. Replay snapshots are archived and
do not count as live race telemetry.

The app remembers your settings and verifies your Steam link on future launches.
With the default settings, the recorder captures solo practice and league driving
across tracks and cars. The server organizes sessions and administrators approve
official league nights. Advanced connection settings are available through the
portable Python command-line client.

Failed deliveries remain queued locally and retry. Closing the app retains the
remaining queue for the next launch. Settings, queue, and rotating recorder.log
files are under %LOCALAPPDATA%\AMSLeagueRecorder.

This executable records game data only. The optional UDP archive is available
through the source/portable command-line client.

Source: https://github.com/hopperj/ams-league-tracker-monitor

STEAM ACCOUNT
Sign into the webapp and choose Download my Windows recorder for personalized setup. Extract the whole ZIP, keeping AMSLeagueRecorder.enroll.json beside Setup, then run Setup. Your browser asks you to approve this recorder. With a generic download or an existing installation, click Link Steam account. Recording and uploads wait until the server confirms the link. Existing settings and queued data are preserved.

AUTOMATIC UPDATES (0.6.0 AND LATER)
The Windows EXE checks for published updates at startup before recording. A
verified update installs and restarts automatically with your saved Steam link,
settings and queue. You do not need to sign into Steam again for an ordinary
update. Skip update & start uses the installed version; failed checks/downloads
also keep the current version. Running recordings are not interrupted.
The installed primary executable is at
%LOCALAPPDATA%\Programs\AMSLeagueRecorder\AMSLeagueRecorder.exe.
Updates replace it safely in place; your shortcuts keep opening the new version.
A verified recovery copy is retained, and failed installation or launch attempts
restore the previous version. Updates download in the background and wait for
five minutes without recording before restarting the app.

If you previously opened a portable EXE from Downloads, close it and run Setup
once. Your saved Steam link and queue are reused. Use the new shortcut afterward
and remove old portable EXE copies. An old installer cannot downgrade a newer
installed recorder. Close the recorder before reinstalling or uninstalling.
Uninstall removes the app and shortcuts but keeps your saved recorder data.
