AMS League Recorder for Windows x64 (Intel and AMD)

One build works on both Intel and AMD 64-bit Windows PCs.
The x64 architecture is also called x86-64 or AMD64; it supports both brands.
Python and the window toolkit are included. No separate Python installation or
compilation is required.

1. Extract this ZIP, then double-click
   AMSLeagueRecorder-Windows-x64-Intel-AMD.exe.
2. In AMS2, select Options > System > Shared Memory > Project CARS 2.
3. The recorder connects and starts automatically. No account, name, or upload
   key is needed. The server detects your AMS2 player name from the game.
4. Setup is optional. The default server is https://ams2.ioresearch.ca:5443.
   Leave the capture code as AUTO to record all sessions. Existing settings
   and queued data continue working when upgrading from an older version.

Green / Transmitting means recent AMS2 data has been received by the server.
Red includes an explanation of what needs attention. Data saved - review means
the server saved the upload but has processing notes; later uploads continue.
A league administrator can review those notes in Recording diagnostics.

The app remembers your settings and starts recording on future launches.
AUTO records solo practice and league driving across tracks and cars. The server
organizes sessions; administrators separately approve official league nights.
Older saved capture codes remain supported. To enable automatic recording, Stop,
open Setup, change the capture code to AUTO, and save/start again.

Failed deliveries remain queued locally and retry. Closing the app retains the
remaining queue for the next launch. Settings, queue, and rotating recorder.log
files are under %LOCALAPPDATA%\AMSLeagueRecorder.

This executable records game data only. The optional UDP archive is available
through the source/portable command-line client.
